## 测试方法

### 代码审查为主
由于环境 Node.js 版本限制（18.x vs 要求 20.9.0），无法直接运行 Next.js 开发服务器。测试将主要基于：

1. **完整代码审查** — 逐页面、逐组件阅读源码，分析逻辑正确性
2. **ESLint + TypeScript 审计** — 汇总所有 lint 错误，分类优先级
3. **i18n 对比** — 对比翻译文件与实际页面使用
4. **数据流分析** — 追踪 localStorage key 的读写一致性
5. **路由导航分析** — 检查页面跳转逻辑、参数传递
