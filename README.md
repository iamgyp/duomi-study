# 多米习题站 (DUOMI Study)

面向儿童的在线学习练习平台，涵盖数学、代数、语文、英语以及**键盘守卫战（打字游戏）**五大核心模块，支持在线做题、自动判分、学习记录、成就系统与盲打训练。全站采用 Minecraft 像素风格 UI。

## ⌨️ 键盘守卫战（Keyboard Defender）打字模块

专为小学生与初学者设计的 **Minecraft 塔防打字练习游戏**。僵尸、苦力怕、骷髅正向村庄推进，在键盘上敲击对应字母即可射箭消灭怪物，保卫村庄！

### 1. 核心玩法
- **塔防战斗引擎**：Canvas 2D 原生像素渲染，自动锁定最近怪物，已打按键实时变绿，击退产生经验球与粒子爆炸。
- **PC 专属 1:1 虚拟键盘**：
  - 8 指标准色彩分区（左手小/无/中/食，右手食/中/无/小，大拇指空格）。
  - 当前目标按键黄色光晕呼吸动画，顶部清晰标示手指指法（如 `左手食指`）。
  - `F` 与 `J` 特殊标记基准盲打微凸定位点。
  - 实体键盘物理敲击实时 3D 下沉微动效与错键红闪反馈。
- **零挫败练习模式**：
  - 怪物到达城墙立正停步等待，不扣除生命值，初学者可从容寻找按键。
  - 极缓步巡逻速度（20px/s），给孩子充分找键时间。
- **守卫挑战模式**：
  - 5 颗红心生命限制，怪物撞墙扣心，考验盲打反应与连击。
- **末影龙 BOSS 决战**：
  - 每关第 5 波末影龙降临，屏幕上方展现经典紫黑分段血条，长词或混合连续算式击破。

### 2. 四大训练课程体系

| 课程分类 | 关卡 / 级别 | 内容说明 |
|----------|-------------|----------|
| **🔤 键位训练** | 7 关循序渐进 | ① 食指定位 `F J`<br/>② 基准行核心 `A S D F J K L ;`<br/>③ 左右延伸 `G H`<br/>④ 上排字母 `Q W E R T Y U I O P`<br/>⑤ 下排字母 `Z X C V B N M`<br/>⑥ 26 字母大乱斗<br/>⑦ 数字键盘 `1 ~ 0` |
| **📖 自然拼读** | Oxford Phonics L1~L5 | ① Level 1: 字母音（ant, bed, cat... 共 24 词）<br/>② Level 2: 短元音 CVC（bat, hen, dig, fox, bug... 共 26 词）<br/>③ Level 3: 长元音 Magic e（cake, bike, home, cute... 共 24 词）<br/>④ Level 4: 辅音组合（ship, chick, thin, frog, star... 共 22 词）<br/>⑤ Level 5: 元音组合（rain, boat, moon, coin, cloud... 共 28 词）<br/>*击破怪物自动触发 Web Speech TTS 纯正英语发音* |
| **🇨🇳 拼音汉字** | 声母/韵母/一至二年级 | ① 声母专项 (23个) & 韵母专项 (24个) & 整体认读音节 (16个)<br/>② 一年级上册生字（天地人日月水火...）与常用词（大小、上下、白云...）<br/>③ 一年级下册生字词（春风冬雪青草红花...）<br/>④ 二年级上册生字词（海洋眼睛跳舞闪电...）<br/>⑤ 二年级下册生字词（乡村儿童碧绿鲜花阳光...）<br/>*支持一键开/关带声调拼音提示，ü 键自动映射为键盘 v* |
| **🧮 口算心算** | 10 / 20 / 50 / 100 以内混合加减 | ① **10以内混合加减法**（基础幼小衔接启蒙，一位数加减混合）<br/>② **20以内混合加减法**（一年级核心重点，进位加法与退位减法混合）<br/>③ **50以内混合加减法**（两位数与一位数/两位数混合加减速算）<br/>④ **100以内混合加减法**（二年级核心挑战，百以内加减混合速度对抗）<br/>*怪物头顶展现算式（如 `8 + 7 =`），玩家纯心算后敲击键盘数字作答击退敌人* |

### 3. 生态战场与成长奖励
- **5 大生态地图**：🌲 草原 (Plains)、🏜️ 沙漠 (Desert)、❄️ 雪原 (Snow)、🔥 下界 (Nether)、🌌 末地 (The End)。
- **Minecraft 武器成长线**：随练习积累经验 XP，依次解锁：
  - 🪵 **木剑猎弓** (0 XP，新手冒险)
  - ⚔️ **铁剑劲弓** (100 XP，进阶守卫)
  - 💎 **钻石神剑** (300 XP，精英勇士)
  - 🌌 **下界合金圣剑** (600 XP，传奇王者)
- **易错键智能排查**：自动统计练习中的错按键，在打字主页汇总「易错键巩固」，针对性攻克薄弱键位。

## 🏆 成就系统

包含 4 个大类、共 **24 个成就勋章**：

- **学习里程碑** — 第一镐、砖石之心、满腹经纶、七天战士、时间领主、键位新星
- **全对与极限** — 开门红、三连胜、神射手、闪电十题、数学神射手、末影屠龙者
- **学科专精** — 数学学徒、书法达人、英语达人、全能冠军、代数商人、口算达人、诗词达人、速认达人、代数学霸
- **图鉴与收集** — 初级收藏家、资深收藏家、成就大师、指尖风暴（解锁钻石神剑）

每次完成练习后自动评估并弹出 Minecraft 风格成就 Toast 动效，支持复制分享。

## 技术栈

| 类别 | 技术 |
|------|------|
| **核心框架** | Next.js 16 (App Router + Turbopack) + React 19 |
| **开发语言** | TypeScript 5 |
| **样式系统** | Tailwind CSS v4 + Minecraft 像素风组件库 |
| **游戏引擎** | Canvas 2D + requestAnimationFrame (原生高性能，无重型依赖) |
| **音频引擎** | Web Audio API 像素合成音效 + Web Speech API 原生 TTS 语音合成 |
| **中文与拼音** | `cnchar` (汉字拼音与笔顺解析) |
| **文档与导出** | `@react-pdf/renderer` (PDF 纯前端排版生成) |
| **国际化** | `next-intl` (中英双语即时切换) |
| **本地存储** | `localStorage` (学习记录、关卡进度、错题本、成就、主题) |

## 快速开始

### 1. 环境准备
- **Node.js >= 20.9.0**
- npm / pnpm / yarn

### 2. 安装与运行

```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev

# 构建生产版本 (Turbopack)
npm run build

# 启动生产服务
npm run start
```

访问 [http://localhost:3000](http://localhost:3000) 即可开始体验！
