# 多米习题站 (DUOMI Study)

面向儿童的在线学习练习平台，涵盖数学、代数、语文、英语以及**键盘守卫战（打字游戏）**五大核心模块，支持在线做题、自动判分、学习记录、成就系统与盲打训练。全站采用 Minecraft 像素风格 UI。

## ⌨️ 键盘守卫战（Keyboard Defender）打字模块

专为小学生与初学者设计的 **Minecraft 主题多模式打字练习游戏**。支持三大截然不同的游戏形式自由切换，并全量覆盖键位、自然拼读、汉字拼音与加减乘除心算！

### 1. 三大游戏玩法模式

| 玩法模式 | 游戏视角与核心体验 | 沉浸特色与反馈机制 |
|----------|-------------------|-------------------|
| 🏹 **城墙弓手** (塔防守卫) | 横向塔防防线，阻击推进的僵尸、苦力怕、骷髅与末影龙 BOSS | 弓箭抛物线射击、实体被击退击飞、TNT 范围爆炸、末影龙大招连算 |
| ⛏️ **深潜矿工** (垂直下挖) | 纵深垂直俯视下潜，从 +64m 表层一路掘进至 -64m 深层基岩与钻石矿脉 | 挥镐碎石物理爆渣粒子、矿石地质分层（煤炭/铁矿/红石/黄金/钻石）、岩浆下渗危机感 |
| 🚂 **矿车狂飙** (极速跑酷) | 横版侧视铁轨疾驰，高速冲刺破除轨道障碍，多轨飞跃与变轨拾取 | 撞碎路障石块粒子、变轨扳道音效、金苹果吃取闪耀特效、超频连击火箭尾焰加速 (Boost) |

- **全模式共享标准指法与反馈**：
  - **双重规则保障**：**练习模式**（零挫败无限心/怪物停步/熔岩停滞）与 **挑战模式**（5 心扣血考验/真实碰撞危机）。
  - **4 档推进速度**：慢速（极缓找键）、中速（平稳进阶）、快速（敏捷挑战）与 **严苛狂暴（极速逼近手速反应极限）**。
  - **10 波战役与加倍怪潮**：战役长度升级为 10 波，每波怪物密度全面翻倍；前 9 波迎战各路怪物/路障/矿层磨练手速，第 10 波决战末影龙 BOSS！
  - **三大玩法专属 BGM 配乐**：纯 Web Audio API 像素合成，三大玩法各自拥有独立主题曲（🏹 城墙弓手：要塞守卫进行曲；⛏️ 深潜矿工：晶洞采矿回想曲；🚂 矿车狂飙：铁轨飞驰狂想曲），支持一键开关与 TTS 朗读智能音量闪避（Ducking）。

### 2. 四大训练课程体系

| 课程分类 | 关卡 / 级别 | 内容说明 |
|----------|-------------|----------|
| **🔤 键位训练** | 7 关循序渐进 | ① 食指定位 `F J`<br/>② 基准行核心 `A S D F J K L ;`<br/>③ 左右延伸 `G H`<br/>④ 上排字母 `Q W E R T Y U I O P`<br/>⑤ 下排字母 `Z X C V B N M`<br/>⑥ 26 字母大乱斗<br/>⑦ 数字键盘 `1 ~ 0` |
| **📖 自然拼读** | Oxford Phonics L1~L5 | ① Level 1: 字母音（ant, bed, cat... 共 24 词）<br/>② Level 2: 短元音 CVC（bat, hen, dig, fox, bug... 共 26 词）<br/>③ Level 3: 长元音 Magic e（cake, bike, home, cute... 共 24 词）<br/>④ Level 4: 辅音组合（ship, chick, thin, frog, star... 共 22 词）<br/>⑤ Level 5: 元音组合（rain, boat, moon, coin, cloud... 共 28 词）<br/>*击破怪物自动触发 Web Speech TTS 纯正英语发音* |
| **🇨🇳 拼音汉字** | 声母/韵母/能力进阶 (5关) | ① 声母专项 (23个) & 韵母专项 (24个) & 整体认读音节 (16个)<br/>② 基础启蒙 · 常用生字（天地人日月水火...）<br/>③ 生活常用 · 双字词语（大小、上下、白云、日月...）<br/>④ 进阶拓展 · 常见生字（春风冬雪青草红花...）<br/>⑤ 丰富识字 · 进阶生字（海洋眼睛跳舞闪电...）<br/>⑥ 词汇大师 · 词语大冲关（乡村儿童碧绿鲜花阳光...）<br/>*支持一键开/关带声调拼音提示，ü 键自动映射为键盘 v* |
| **🧮 口算心算** | 加减进阶 & 乘除专项 (8关) | **加减心算进阶**：<br/>① 10以内加减法（基础启蒙，一位数加减速算）<br/>② 20以内进退位加减（核心速算，进退位专项强化）<br/>③ 50以内两位数加减（进阶强化，两位数混合速算）<br/>④ 100以内加减挑战（百数对决，大数心算巅峰）<br/>**乘除与四则混合**：<br/>⑤ 九九乘法表专项（乘法核心，2~9表内乘法口诀肌肉记忆）<br/>⑥ 表内除法速算（逆向互逆运算，被除数≤81表内除法）<br/>⑦ 乘除双向混合（乘法与除法即时切换，思维快速转换）<br/>⑧ 四则运算大满贯（加减乘除四合一全能对决，末影龙连算大挑战）<br/>*怪物头顶展现算式（如 `7 × 8 =` 或 `56 ÷ 7 =`），玩家纯心算后敲击键盘数字作答击退敌人* |

### 3. 生态战场与成长奖励
- **5 大生态地图**：🌲 草原 (Plains)、🏜️ 沙漠 (Desert)、❄️ 雪原 (Snow)、🔥 下界 (Nether)、🌌 末地 (The End)。
- **Minecraft 武器成长线**：随练习积累经验 XP，依次解锁：
  - 🪵 **木剑猎弓** (0 XP，新手冒险)
  - ⚔️ **铁剑劲弓** (100 XP，进阶守卫)
  - 💎 **钻石神剑** (300 XP，精英勇士)
  - 🌌 **下界合金圣剑** (600 XP，传奇王者)
- **易错键智能排查**：自动统计练习中的错按键，在打字主页汇总「易错键巩固」，针对性攻克薄弱键位。

## 🏛️ 记忆神殿（Memory Temple）认知记忆模块

专为小学低年级儿童设计的**记忆力与高阶思维训练专区**。摆脱死记硬背，从感官专注力跃升为深度情境理解与逻辑图式建构：

### 1. 三大核心训练体系

| 训练殿堂 | 核心机制 | 认知训练维度 |
|----------|----------|--------------|
| 📜 **探险家日志** (高迁移推荐 ⭐) | `[场景展示]` ➔ `[时序/要素重构]` ➔ `[逻辑验证]` | 故事结构理解、事件先后时序重组、要素归类、数学应用建模、因果推导 |
| 🎵 **音符盒秘境** | Simon Says 视听序列节奏 | 视听双通道短时工作记忆、即时抗干扰专注力、手脑耳多感官协同 |
| 🃏 **末影宝藏** | 翻牌配对消消乐 (Memory Match) | 空间位置记忆、像素图鉴、汉字↔拼音、加减乘除算式↔答案、英文图词互认 |

### 2. 高迁移认知闭环（探险家日志）
- **阶段一：场景故事沉浸展示**
  - 30~50 字短情境故事（涵盖森林探险、村庄物资、守卫小侦探等篇章）。
  - 支持 **拼音全拼辅助注音**、**Web Speech 原生 TTS 语音朗读**、关键要素（角色、时间、物品、数量）高亮标记。
- **阶段二：要素重构与时序拼图**
  - **时序重构**：将打乱的 4 项事件卡片依据时间发生顺序排回正确位置（对标小学语文看图写话与复述故事）。
  - **要素归类**：将出现的物品分类放进不同箱子（如【出发带的工具】vs【途中遇见的痕迹】）。
- **阶段三：语义提取与逻辑验证**
  - **数学建模**（如背包剩余数量减法计算：`3 - 1 = 2`）；
  - **细节辨析**（真伪判断、空间方位感知）；
  - **因果与反事实推理**（起因溯源、条件假设推导）。

## 技术栈

| 类别 | 技术 |
|------|------|
| **核心框架** | Next.js 16 (App Router + Turbopack) + React 19 |
| **开发语言** | TypeScript 5 |

| **文档与导出** | `@react-pdf/renderer` (PDF 纯前端排版生成) |

| **本地存储** | `localStorage` (学习记录、关卡进度、错题本、成就、主题) |

## 快速开始

### 1. 环境准备
- **Node.js >= 20.9.0**
- npm / pnpm / yarn

### 2. 安装与运行

```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev

# 构建生产版本 (Turbopack)
npm run build

# 启动生产服务
npm run start
```

访问 [http://localhost:3000](http://localhost:3000) 即可开始体验！
